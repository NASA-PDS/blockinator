# Security Policy

This document describes the security policy of the Blockinator.


## Supported Versions


| Version | Supported |
|:--------|:---------:|
| 0.0.0   | ✅        |
| <0.0    | ❌        |


## Reporting a Vulnerability

To report a vulnerability, [please submit an issue on our tracker](https://github.com/NASA-PDS/blockinator/issues/new?template=vulnerability-issue.md).
